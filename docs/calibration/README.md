# Cambridge calibration study

Status: Phase 8.5A baseline

## Sources and copyright boundary

The study uses only derived measurements and task characteristics from public Cambridge English material:

- [C1 Advanced exam format](https://www.cambridgeenglish.org/exams-and-tests/qualifications/advanced/format/)
- [C1 Advanced preparation page and official sample papers](https://www.cambridgeenglish.org/exams-and-tests/qualifications/advanced/preparation/)
- [C1 Advanced Handbook for teachers](https://www.cambridgeenglish.org/Images/167804-c1-advanced-handbook.pdf)

No sample-paper passage, question or answer key is copied into the repository. Counts were derived from the two official Reading and Use of English sample papers linked by Cambridge on the preparation page on 2026-09-17.

## Interpretation

Each profile separates:

- **Official format rule:** expressly stated by Cambridge.
- **Observed benchmark:** a measurement from two official exemplars; not a universal Cambridge rule.
- **Internal target:** a provisional generation/validation range chosen from the observed evidence.

The sample size is small. Internal ranges are guardrails for obvious under-calibration, not claims that every authentic Cambridge paper falls inside them. Profiles must be versioned when more evidence is added.

Word counts exclude titles, instructions, question/options text for Parts 1–6, gap markers and page furniture. Part 7 includes the base text and all seven paragraph options. Part 8 includes the source sections but not the ten prompts. PDF extraction can vary slightly around hyphenation, so ranges should not be used as one-word pass/fail boundaries.
