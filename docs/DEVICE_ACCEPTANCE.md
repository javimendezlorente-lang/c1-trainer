# Device acceptance — Phase 8.5D

These are manual acceptance items. They must be run against the deployed GitHub Pages URL; unchecked boxes are not evidence of a pass.

## Installation — iPhone/Safari

- [ ] Open the deployed URL in Safari.
- [ ] Add to Home Screen.
- [ ] Launch the installed PWA.
- [ ] Confirm the C1 Trainer icon/name and standalone display.

## Persistence

- [ ] Complete one exercise.
- [ ] Close the application.
- [ ] Reopen it.
- [ ] Confirm the attempt remains.
- [ ] Confirm Progress remains.
- [ ] Confirm Error Bank remains.

## Review

- [ ] Create or use a due review card.
- [ ] Complete a review.
- [ ] Close and reopen.
- [ ] Confirm the ReviewEvent remains.
- [ ] Mark one card mastered; close/reopen; confirm mastered remains.
- [ ] Restore it to active; close/reopen; confirm active remains.
- [ ] Archive it; restore it to active; confirm history is unchanged.

## Offline

- [ ] Open the app online once, then close it.
- [ ] Enable Airplane Mode and reopen the installed PWA.
- [ ] Confirm Home, Practice, exercise opening, answering, correction, save, Progress and Review all work.

## Backup

- [ ] Export a backup on iPhone.
- [ ] Confirm the file/share sheet works.
- [ ] Import the same backup and confirm duplicate events are not created.

## PWA update

- [ ] Create learning history.
- [ ] Deploy a newer build and allow the service worker to update.
- [ ] Reload/reopen and confirm historical data survives.

## 390 px usability

- [ ] No horizontal overflow.
- [ ] Reading text is usable.
- [ ] Review controls are usable.
- [ ] Practice controls are usable.
- [ ] A long Part 7 passage is usable.
